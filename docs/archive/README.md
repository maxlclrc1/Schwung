# Archive

Historical records, kept for their reasoning and evidence. None of them describes the app as it is now; the code,
and the active documents in [`../`](../README.md), do. Nothing here needs updating.

## Before the 66-day Life Reset (October 2026)

The first program (a quiz, a larger habit library, automatic step-downs) and the "V2" work that preceded the Life
Reset. Removed from the app; the code is in Git history.

- `HABIT_SCIENCE_AUDIT.md`, `HABIT_SCIENCE_V2_ARCHITECTURE.md`: the habit-science audit and the V2 specification.
- `SCHWUNG_V2_*.md`: V2's evidence register (sources behind many habit rules), scheduled habits, accessible
  movement, fitness decision and prototypes, the physiotherapist review packet, plan validation, experience
  reviews and release readiness.
- `SCHWUNG_PRODUCT_RETHINK.md`, `SCHWUNG_FIELD_NOTES_PROTOTYPE.md`, `SCHWUNG_HABIT_COMPETITOR_REVIEW.md`: the
  rethink that led to the Life Reset.
- `SCHWUNG_LIFE_RESET_PILOT.md`, `SCHWUNG_LIFE_RESET_CHALLENGES.md`, `SCHWUNG_LIFE_RESET_HABIT_AUDIT.md`: the Life
  Reset as an in-app pilot, and the habit audit that shaped today's catalogue.
- `LATER.md`: the first backlog. Partly done since (the tip jar, 19 translations including Turkish, backup restore).
