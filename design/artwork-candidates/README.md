# Artwork candidates

Drop ChatGPT's generated images here so they can be checked and integrated. Nothing in this folder is used by
the app; approved art is graded, compressed and copied into `assets/` separately.

## How to upload (from a phone or computer)
1. Open https://github.com/maxlclrc1/Schwung/tree/main/design/artwork-candidates
2. Tap **Add file → Upload files** (on a phone, use desktop mode in the browser if the button doesn't show).
3. Add the image(s) and commit directly to `main`.
4. Tell Claude "candidate uploaded".

## Naming
`<asset>-<theme>-v<n>.png`, for example `a1-dark-v1.png`, `a1-dark-v2.png`, `a1-light-v1.png`.

- Upload the **original file** ChatGPT gives you (download it, don't screenshot it). PNG is best.
- Optional: add a `.txt` with the same name containing the prompt you used, e.g. `a1-dark-v1.txt`.
